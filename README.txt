DEMO REVISTA DIGITAL - MÉXICO TRAVEL MAGAZINE

Archivos:
- index.html
- style.css
- app.js

Cómo usar:
1. Descomprime el ZIP.
2. Abre index.html en tu navegador.
3. También puedes subir la carpeta completa a GitHub Pages, Netlify o Vercel.

Notas:
- El demo usa imágenes remotas de Unsplash.
- Puedes sustituir los fondos por imágenes propias en el CSS.
- El efecto de hojear usa PageFlip desde CDN.
